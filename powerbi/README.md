# Power BI Dashboard

This folder contains the interactive Power BI report for the FIFA World Cup Evolution Analytics project (1994–2026).

## Final deliverable

`FIFA_World_Cup_Evolution_1994_2026.pbix`

The report contains four analytical pages:

1. Growth & Global Impact
2. Growth & Comparisons
3. Sporting & Venue Performance
4. Financial & Global Reach

The report combines PostgreSQL-prepared analytical data with DAX measures for tournament-over-tournament comparisons, historical benchmarks, sporting performance, venue utilisation, financial performance and global audience reach.

> The PBIX file is uploaded separately because it is a binary Power BI file.
