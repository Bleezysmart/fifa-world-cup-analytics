# Project Reports

This folder contains the presentation-ready outputs for the FIFA World Cup Evolution Analytics project.

## Files

- `FIFA_World_Cup_Evolution_1994_2026_Report.pdf` — full analytical project report covering the project origin, database build, data preparation, SQL analysis, Power BI modelling, key findings, limitations and final conclusion.
- `FIFA_World_Cup_Evolution_1994_2026_Dashboard.pdf` — exported four-page Power BI dashboard for easy viewing without Power BI Desktop.

These binary PDF deliverables are uploaded separately.
